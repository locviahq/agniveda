# AGNIVEDA

**Slow-churned. Slow-simmered.**

AGNIVEDA is a premium Indian bilona ghee brand. Our ghee is made from milk sourced from our family's own cows and buffaloes, using the traditional curd-based bilona method: milk is set into curd, curd is churned into butter, and butter is slowly heated into ghee.

This repository contains the brand website.

---

## Status

Work in progress. The website is being built one file at a time.

Product details, certifications, laboratory results and marketplace links are pending verification. Nothing on the site should be treated as final until marked as verified.

## Tech

- No frameworks, no build tools, no backend
- Hosted on GitHub Pages
